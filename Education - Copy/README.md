# GIET University Website

A premium, modern, and highly responsive landing page for **GIET University**, designed to showcase academic excellence, cutting-edge research, campus culture, and exceptional placement records.

---

## 🚀 Live Preview & Aesthetics

The interface is built with premium aesthetics, rich typography, smooth transitions, and dynamic visual hierarchies that align with modern web design standards.

### Features
*   **Dynamic Navigation:** Sticky navigation bar with blur backdrop filter effects and reactive mobile drawer menu.
*   **Key Statistics Bar:** Trust-building metrics highlighted with clean spacing and contrasting indigo/amber accents.
*   **Academic Explorer:** Categorized highlight cards representing different Schools of Excellence (Engineering, Management, Agriculture).
*   **Research & Innovation Section:** High-contrast dark mode segment displaying advanced lab facilities, key research affiliations, and latest breakthroughs.
*   **Placement & Corporate Relations:** Recruiter recognition matrix with clean typography representations of key industry partners (Google, Amazon, Deloitte, etc.).
*   **Interactive Campus Life Gallery:** Multi-column masonry layout capturing the essence of student life, facilities, and academic hubs.
*   **Notice Board & happenings:** Dual-layout news grid featuring the latest announcements, events, and a chronological notice bulletin board.

---

## 🛠️ Technology Stack

1.  **HTML5**: Semantic elements (header, nav, section, article, footer) for SEO and accessibility.
2.  **Tailwind CSS**: Modern utility-first styling with custom font families and colors.
3.  **Iconify Icons**: Lightweight, scalable vector icons from the Solar linear collection.
4.  **JavaScript (ES6+)**: Custom dynamic client-side behaviors (sticky headers, responsive menus).

## ⚡ Quick Start

### Prerequisites
To run this project locally, you need a simple HTTP server. If you have Node.js installed, you can use `npx`.

### Running Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Dhanush0058/Demo-Project3.git
   cd Demo-Project3
   ```

2. Start a local server:
   ```bash
   # Using http-server (npm)
   npx http-server -p 8080
   
   # Or using Python 3
   python -m http-server 8080
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```

## 🎯 SEO & Performance Optimization

*   **Semantic HTML**: Implements a clean tag structure (`<h1>` per page, `<article>` for news posts).
*   **Metadata**: Formatted header titles and meta definitions.
